# ShipRSImageNet 外部数据接入与训练设计

日期：2026-08-17  
状态：已确认设计，待制定实施计划

## 1. 目标

在不使用官方测试集、不改变模型最终25类输出定义的前提下，引入 ShipRSImageNet V1.1，提高稀有舰船类别 HM（航母）、LQS（两栖舰）和 QHS（驱护舰）的召回率与置信度可分性，并通过更可靠的验证流程选择分类别置信度阈值。

官方已明确验证集使用水平框，并基于水平框标注进行评价。因此本方案的训练标注、OOF预测、匹配、阈值搜索和最终评测统一采用水平框及水平框IoU，不引入旋转框评价口径。

最终硬指标保持不变：

- 官方总体召回率不低于 85%；
- 官方总体虚警率不高于 20%；
- 期望内部安全工作点为总体召回率约 87% 或更高、总体虚警率约 18% 或更低。

本设计采用以下已确认方案：

1. 10% 官方数据作为按原始场景分组的本地盲测集；
2. 其余 90% 官方数据进行三折、按原始场景分组的 OOF 验证；
3. ShipRSImageNet 采用保守类别映射，只进入训练数据；
4. 最终模型使用官方数据进行低学习率微调；
5. 暂不进行模型结构消融。

## 2. 约束与原则

### 2.1 数据边界

- ShipRSImageNet 不进入官方域验证集或本地盲测集。
- 本地盲测集一旦生成，在三折训练、模型选择和阈值搜索期间不得评估或查看预测结果。
- 阈值只根据三折 OOF 官方数据预测确定，随后原样应用于本地盲测集和官方隐藏测试集。
- 不使用测试标注调整模型、类别映射、阈值或后处理参数。

### 2.2 场景隔离

官方数据由原始大图裁剪成多个 patch。同一原始大图产生的所有 crop 必须属于同一个数据集合或同一个折，禁止按单个 crop 随机拆分。

场景分组键按数据源分别生成：

- 对带 `_cropN` 后缀的样本，移除 crop 编号后作为父场景键；
- 对其他具有明确原始影像编号的来源，使用完整原始影像编号作为父场景键；
- 无法可靠恢复父场景的样本使用保守规则：将可能相关的文件归为同组，而不是拆开；
- 分组结果输出审计 CSV，记录文件名、数据源、父场景键和最终集合/折号。

### 2.3 可复现性

训练报告必须记录：

- ShipRSImageNet 版本、下载地址、压缩包 SHA-256 和使用条款；
- 官方数据与外部数据的映射规则及排除规则；
- 分组划分随机种子和分组清单；
- 数据转换脚本版本；
- 每次训练配置、初始化权重、随机种子和最终 checkpoint；
- OOF 阈值文件及阈值搜索约束；
- 所有训练数据来源比例。

## 3. ShipRSImageNet 数据接入

### 3.1 输入格式发现

下载完成后只读取 ShipRSImageNet V1.1 的目录结构、类别表、COCO/VOC 标注和许可说明。必须优先使用官方提供的 COCO HBB 标注，以匹配比赛水平框评价。只有某个已映射样本确实缺少HBB时，才允许把其OBB或多边形按 `xmin=min(x_i), ymin=min(y_i), xmax=max(x_i), ymax=max(y_i)` 转换为最小外接水平框；转换来源和转换前几何信息写入审计记录。不得把旋转框坐标直接当作水平框，也不得在本流程中使用旋转IoU。

转换程序必须在任何写入前验证：

- 图像文件存在且文件名唯一；
- 类别 ID 与类别名称一一对应；
- 标注框位于图像范围内且宽高为正；
- 输出框均为COCO水平框 `[x, y, width, height]`，且不包含角度字段；
- 每个映射类别均产生非零实例；
- 输出图片 ID、标注 ID 全局唯一；
- 输出 COCO 类别 ID 与当前25类定义一致。

验证失败时停止转换并输出明确错误，不静默丢弃未知类别或损坏标注。

### 3.2 保守类别映射

第一轮采用以下映射；只有语义明确的类型才进入对应比赛类别。

#### HM（category_id=0）

- Other Aircraft Carrier
- Enterprise
- Nimitz
- Midway

#### LQS（category_id=1）

- Other Landing
- YuTing LL
- YuDeng LL
- YuDao LL
- YuZhao LL
- Austin LL
- Osumi LL
- Wasp LL
- LSD 41 LL
- LHA LL
- 明确标注为 amphibious transport dock 或 amphibious assault ship 的类型

#### QHS（category_id=2）

- Ticonderoga
- Other Destroyer
- Atago DD
- Arleigh Burke DD
- Hatsuyuki DD
- Hyuga DD
- Asagiri DD
- Other Frigate
- Perry FF

#### MS（category_id=3）

MS 只有在官方类别说明确认其含义为民用/商用船舶后才启用外部映射。确认前，ShipRSImageNet 的商船类别全部作为未映射舰船处理，不进入 MS 正样本。

#### 不映射类别

以下类别不强行映射到 HM/LQS/QHS：

- Other Ship、Other Warship；
- Submarine、Patrol、Commander；
- Auxiliary Ship、Medical Ship、Test Ship、Training Ship；
- 无法确认与比赛定义一致的商船和小艇；
- Dock。

未映射的舰船实例不得被当成背景。转换后应作为忽略区域；如果当前 MMDetection 数据流程不能正确支持逐实例忽略，则包含未映射舰船的图像不进入第一轮外部训练集。两种处理方式以“不会把真实舰船训练成背景”为选择标准。

### 3.3 去重

ShipRSImageNet 已包含 HRSC2016、FGSD 及其他来源的部分数据，因此第一轮不再单独叠加 HRSC2016 或 FGSD。

去重分两级：

1. 精确文件哈希去除完全相同图像；
2. 感知哈希和尺寸/标注位置联合检查近重复、重编码和重复裁剪图。

必须同时检查 ShipRSImageNet 内部重复，以及它与官方训练、OOF验证和本地盲测数据之间的潜在重复。与官方 OOF 或盲测数据近重复的外部图像从训练数据中排除，并记录排除原因。

## 4. 官方数据重新划分

### 4.1 固定10%本地盲测集

以父场景为最小单位，从官方数据中划分约10%作为本地盲测集。划分目标按优先级排序：

1. 父场景不跨集合；
2. 25类均尽可能覆盖；
3. HM、LQS、FSC等稀有类别在盲测集中有代表性，但不得抽空开发集；
4. 总图像数和总目标数接近10%；
5. 各数据源均尽可能覆盖。

盲测集清单生成后冻结，三折训练期间不运行推理。

### 4.2 90%开发集的三折OOF

剩余90%官方数据按父场景和多标签类别分布划为三个互斥折。每个样本恰好在一次训练中作为验证样本：

- Run 1：Fold B + Fold C + 外部数据训练，Fold A 验证；
- Run 2：Fold A + Fold C + 外部数据训练，Fold B 验证；
- Run 3：Fold A + Fold B + 外部数据训练，Fold C 验证。

三个验证结果合并成覆盖90%官方开发集的 OOF 预测。模型结构、训练轮数、初始化方式、外部数据版本和映射必须相同，只允许训练折不同。

## 5. 训练数据采样

外部数据数量可能显著大于官方稀有类别，不能直接无权重拼接。训练加载器按来源控制采样，初始目标比例为：

- 官方训练折：50%～60%；
- ShipRSImageNet 已映射正样本：30%～40%；
- 合法保留的外部背景/困难样本：不超过10%。

上述比例是数据来源采样目标，不改变25类最终输出定义。官方数据始终占多数，以降低传感器、清晰度、色彩和标注风格差异带来的域偏移。

对HM和LQS可继续使用类别均衡采样，但应设置重复上限，避免少量官方样本在单个 epoch 内被过度重复。外部图像进行与官方域一致的分辨率退化、轻度模糊、噪声和压缩增强；增强参数根据两域目标像素尺寸统计确定，不使用未经核验的强风格迁移。

## 6. 四次完整训练安排

### Run 1～3：三折OOF训练

- 初始化：三次使用相同的当前基础权重策略；
- 数据：两个官方训练折＋去重后的映射ShipRSImageNet；
- 验证：剩余一个官方折；
- checkpoint选择：仅依据该官方验证折；
- 输出：逐折预测JSON、逐类指标、训练日志和checkpoint。

训练期间可额外计算ShipRSImageNet内部验证指标，用于发现外部标签或转换错误，但不得用它选择最终比赛阈值。

### Run 4：最终模型训练与官方域微调

Run 4分为连续两个阶段，使用同一模型权重延续训练：

1. 混合阶段：90%官方开发集＋映射ShipRSImageNet；
2. 官方域微调阶段：只使用90%官方开发集，以较低学习率继续训练，校准模糊度、传感器风格和类别置信度。

官方域微调不改变类别映射和后处理逻辑。其训练轮数由前三折中统一确定的训练曲线规律设定，不根据本地盲测结果反复调整。

如果第四次训练出现明显异常且训练预算允许，第五次训练仅用于使用另一固定随机种子复现同一最终方案，不引入新的结构或数据规则。

## 7. 阈值选择与最终评估

### 7.1 OOF阈值

将Run 1～3对各自验证折产生的预测合并，使用现有分类别阈值搜索工具寻找工作点。选择原则：

- 官方总体 Recall 不低于85%；
- 官方总体 FDR 不高于20%；
- 优先选择两项硬指标最小安全余量最大的工作点；
- 初始目标为 Recall约87%或更高、FDR约18%或更低；
- 同时报告 ship、aircraft、vehicle 三个大类及25个细分类指标；
- 对HM、LQS、FSC报告基于场景或图像重采样的置信区间。

阈值文件包含类别ID、类别名、阈值、TP、FP、FN、Recall、FDR和生成数据版本。阈值一旦在OOF结果上确定即冻结。

### 7.2 本地盲测

Run 4训练完成并冻结阈值后，才允许对10%本地盲测集评估一次。盲测结果只用于判断方案是否满足提交条件，不再用于调整训练或阈值。

若盲测未通过，记录失败并进入下一轮设计，而不是继续在同一盲测集上迭代参数。

## 8. 产物

实施完成后应生成：

- ShipRSImageNet原始类别统计与映射统计；
- 外部数据映射/忽略/排除清单；
- 精确哈希和近重复审计报告；
- 官方父场景分组清单；
- 10%盲测集清单和90%开发集三折清单；
- 三折训练配置和OOF预测；
- OOF阈值JSON/CSV及过滤后预测；
- Run 4最终配置、checkpoint和训练日志；
- 本地盲测一次性评估报告；
- 可写入比赛报告的数据来源、许可、映射和复现实验说明。

## 9. 验收标准

数据阶段验收：

- 父场景不存在跨折或跨盲测集泄漏；
- ShipRSImageNet与官方OOF/盲测近重复样本已排除；
- 未映射舰船未被错误训练为背景；
- HM、LQS、QHS映射样本均通过类别和框可视化抽检；
- HBB来源统计、OBB/多边形转HBB统计可复现，最终评估只使用水平框IoU；
- 所有转换统计可由同一命令复现。

训练阶段验收：

- 三折全部完成且每个官方开发样本恰好有一份OOF预测；
- 三折使用一致的数据规则和训练配置；
- OOF官方总体Recall与FDR满足硬指标并保留合理安全余量；
- 最终模型通过一次性本地盲测，或明确记录未通过并停止提交该方案。

## 10. 风险与控制

- **域偏移**：官方样本保持多数，并进行最终官方域微调。
- **标签体系不一致**：采用保守映射，语义不明确的实例忽略或排除。
- **重复数据泄漏**：使用父场景分组、精确哈希和感知哈希三重检查。
- **稀有类别阈值过拟合**：使用覆盖90%官方数据的OOF预测，而非单个小验证集。
- **外部数据压制原类别**：按来源采样并监控飞机、FSC和MS的逐类退化。
- **许可风险**：保存数据条款和来源记录；ShipRSImageNet按其学术用途和Google Earth相关条款使用，不重新分发原始数据。
